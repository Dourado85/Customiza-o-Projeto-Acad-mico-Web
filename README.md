# Desenvolvimento Web I — Atividade Avaliativa

Projeto acadêmico baseado no HTML fornecido pelo professor.

## Requisitos
- HTML5 semântico
- CSS3 externo
- Hero com parallax
- Galeria com 4 imagens
- Carrossel automático com CSS/@keyframes
- Carrossel manual com JavaScript
- Vídeo HTML5 preparado para MP4 local
- Vídeo externo via iframe
- Media Queries / mobile-first
- prefers-reduced-motion
- Formulário e footer estilizados

## Estrutura
```text
desenvolvimento-web-i/
├── index.html
├── README.md
├── .gitignore
├── css/style.css
├── js/script.js
├── img/
└── video/
```

## Execução
Abra a pasta no VSCode e execute `index.html` com Live Server.
